# home

Pictures here appear inside the photo strips on irie's home page, for everyone, in every theme.

1. Put up to 4 pictures in this folder (JPG or PNG, about 800 px on the long side is plenty).
2. List them in `home.json`:

```json
{ "photos": ["me-and-irish.jpg", "us-2.jpg", "us-3.jpg"] }
```

With 1 picture, every frame shows it. With 2 or 3, they repeat in order. Leave the list empty to show the plain pink and purple placeholders.

A person can also pick pictures just for themselves in Settings, under "Home page pictures". Those win over this folder on that device.
